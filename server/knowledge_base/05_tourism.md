# 农文旅运营

## 数据说明
农文旅板块的 KPI、路线表与活动表目前为版面演示用虚拟数据，便于汇报排版预览；精细经营数据需以二期核销与问卷系统接入后为准。地理锚点（沙门村、燕羽山、八道河村）来自台账真实村庄名称，但并非精确 GIS 客流。

## 演示指标
- 内容侧景观题材：花海季，台账视频如「大美延庆赏樱花」。
- 满意度：4.63 分（五分制，演示样本 N=186）。
- 客源地结构（虚构）：城区兴趣约 82%，同城与邻省自驾约 64%，研学机构团约 36%。

## 活动案例
- 农事季节内容：香椿季山区春播与采收，代表选题「五一前后出售香椿了」，祁嫂子单条分成样例 ¥3.08。
- 乡村景观与共情表达：大美延庆赏樱花、家门口繁华似锦；郭大嫂以「家人们」的口语人设增强亲切感；春娥姐结合反诈提醒与乡村自豪议题。

## 二期规划
基于一年以上核销与票务时序数据识别淡旺季窗口，提前约两个月推送主题活动排期。演示排期包括冬季「村味年俗节」、春季「香草体验月」，并预留空白周六承接跨村导流团单，避免与兄弟村活动撞期。
