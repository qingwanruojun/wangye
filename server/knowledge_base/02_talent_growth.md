# 银发主播成长体系

## 六阶成长路径
1. 入门认知
2. 拍摄剪辑
3. 直播基础
4. AIGC 应用
5. IP 打造
6. 种子讲师

当前台账均值处于第 2—3 阶之间，整体进度约 68%。多数账号已能稳定拍摄剪辑与周更，集体短板集中在直播预热、前 3 秒钩子、完播率与直播留人。

## 三级活跃度预警
- 7 天未活跃：提醒。
- 15 天未发布：橙色预警。
- 30 天直播或发布缺失：严重预警。
实践团与村委可据此触发结对陪练，重点关注直播场观偏低、政策类稿件互动异常的账号。

## 一人一档数字画像
档案包含视频号公开昵称、内部建档编号、年龄、数字化评分、内容偏好、技能标签（直播、讲解、拍摄、手工）、六阶阶段提示与数据轨迹。姓名已脱敏，仅保留昵称或编号。
