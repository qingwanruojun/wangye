# 乡村助农模式可复制性评估（AHP）

## 评估体系
目标层为「乡村助农模式村庄适配度综合评价」。准则层四类：人口适配度、资源适配度、基础条件适配度、组织与外部支持；指标层为 C1—C12 共十二项二级指标，对应《智赋银龄》报告表 7 的分级标准。

## 计算公式
先将各指标换算到 0—1：Cᵢ′ = Cᵢ / 100。

- 资源吸引力：A = 0.35·C4′ + 0.35·C5′ + 0.30·C6′
- 落地可行性：F = 0.25·C7′ + 0.25·C8′ + 0.15·C9′ + 0.20·C10′ + 0.15·C11′
- 耦合势能：RVCPM = √(A² + F²)

气泡半径按各村 RVCPM 相对本片最大值归一。C1—C3 与 C12 计入民政教育侧综合呈现与帮扶规则，与 A/F 并联展示；完整权重以 AHP 一致性检验后的矩阵为准。

## 四象限判读
- 明星区：A、F 均高，优先推广。
- 潜力区：资源足、可行性待补，专项帮扶基建与执行。
- 机会区：条件好、资源待养，可做配套或二批试点。
- 边缘区：A、F 双低，重点帮扶并实地踏勘。

## 目标村情景推演
页面提供 10 项滑杆用于答辩现场演示，包括老龄化率、人口规模与市场腹地、红色文化资源、非遗与传统手艺、高价值农产品与品牌化、自然景观与环线联动、村两委积极性、宽带与移动网络、物流配送与冷链、村集体运营成熟度、乡贤与青年志愿者供给等，可对标映射到 C1—C12。

## 跨村推广问题库
沉淀他村踩坑与已验证方案，支持村委与运营专员按关键词检索并复盘，内容包括积极性、冷链、话术、回款等主题，服务跨村落地决策。
