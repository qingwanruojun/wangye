# 常见问答

## 这个看板是做什么的？
它是青韵馨香实践团的银发乡播数据中控平台，用一份台账跟踪银发主播成长、视频号流量、电商分成、农文旅运营和村庄复制适配度，并以适老化大字界面呈现。

## 数据是真的还是演示的？
主播账号、原创条数、播放、点赞、收藏、创作分成来自《村民账号信息》台账与视频号后台摘录，属于真实台账样本。农文旅板块中的满意度、客源地、活动人次与金额是演示用虚拟数据，页面已用丝带标识区分。

## 重点跟踪了多少账号？
10 个重点跟踪账号（原创合计 218 条）；台账覆盖 16 个账号，原创内容合计 226 条。

## 目前最大的短板是什么？
集体短板是完播率不高、直播预热与留人偏弱、短视频与直播联动不足，以及政策类题材的互动结构需要陪练。

## 农户能拿到哪些收益？
可查样例包括创作分成 ¥333.68、直播收入 ¥218.95、农户侧分成 ¥27.61（含优质原创激励 ¥19.03），文档期合计 ¥552.63。

## 如何复制到其他村庄？
使用 AHP 村庄适配度评估：十二项二级指标、A/F/RVCPM 公式与四象限判读，先做资源与可行性评估，再按明星区、潜力区、机会区、边缘区制定推广或帮扶策略。

## AI 助手怎么工作？
助手采用 RAG（检索增强生成）：先把问题在本地知识库中做相似度检索，取出最相关的段落，再组织回答并附上来源。若配置了大模型 API，则由模型基于检索结果生成；未配置或后端未启动时，页面使用内置离线答案演示。LoRA 微调脚手架可让模型学习本项目的问答口吻与数据口径。

## 后端怎么启动？
在项目根目录运行 `pip install -r server/requirements.txt`，然后执行 `python -m uvicorn server.app:app --port 8000`。浏览器打开 http://127.0.0.1:8000 即可同时访问页面与问答接口。静态部署的页面会自动探测本机 8000 端口，探测不到时使用内置演示知识库。

## LoRA 微调怎么训练？
先安装训练依赖 `pip install -r server/requirements-training.txt`，然后运行 `python server/training/prepare_dataset.py` 生成训练数据，再执行 `python server/training/train_lora.py --model Qwen/Qwen2.5-0.5B-Instruct`。脚本基于 transformers + peft，默认只训练注意力层的 q/k/v/o 投影，适配器输出到 `server/training/output/lora-adapter`。启动后端时设置 `LOCAL_MODEL_PATH`（基座模型路径）与 `LORA_ADAPTER_PATH`（适配器目录），助手就会优先使用本地 LoRA 模型生成回答；未设置时自动回退到远程 LLM 或抽取式 RAG。
