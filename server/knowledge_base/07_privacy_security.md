# 隐私与安全合规

## 多级权限
系统设置四类角色：超级管理员、村管理员、运营专员、志愿者。村内数据相互隔离，收益数据默认仅村委与项目管理员可见，操作日志全量留存。

## 隐私保护
- 姓名、电话、证件信息自动脱敏，前端只展示视频号昵称或内部编号。
- 原始数据禁止向第三方提供或未脱敏流转。
- 每日凌晨执行全量备份，支持时间点恢复。
- 不向老人采集操作行为数据，仅使用台账与视频号后台公开指标。

## AI 问答助手的数据边界
问答助手只检索项目内知识库文档（台账摘要、规则说明），不读取村民原始 Excel 与证件信息。回答会标注检索来源，便于人工复核；涉及个人敏感信息时不作推断。若接入外部大模型，仅发送问题与检索到的公开摘要片段，不发送原始个人信息。
