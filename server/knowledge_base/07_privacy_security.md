# 隐私与安全合规

## 隐私保护（已落实）
- 姓名、电话、证件信息脱敏，前端只展示视频号昵称或内部编号。
- 原始 Excel 台账不入库、不随代码仓库发布；仓库与页面仅保留昵称化摘要。
- 不向老人采集操作行为数据，仅使用台账与视频号后台公开指标。

## 多级权限、审计与备份（规划中）
- 计划设置超级管理员、村管理员、运营专员、志愿者四类角色，实现村内数据隔离。
- 计划记录登录、查询与导出操作，形成审计日志。
- 计划每日执行全量备份，支持时间点恢复。
- 当前演示版尚未接入登录、鉴权、审计与备份系统，以上能力不作为已实现承诺。

## AI 问答助手的数据边界
问答助手只检索项目内知识库文档（台账摘要、规则说明），不读取村民原始 Excel 与证件信息。回答会标注检索来源，便于人工复核；涉及个人敏感信息时不作推断。若接入外部大模型，仅发送问题与检索到的公开摘要片段，不发送原始个人信息。
