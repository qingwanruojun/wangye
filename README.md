# 银发乡播 · AI 适老化大数据服务看板

乡村助农模式可复制评估体系与数据中控可视化平台（公益轻量版）

## 功能模块

- **银发主播成长** — 主播人才档案与成长轨迹追踪
- **新媒体流量 AI** — 新媒体运营数据智能分析
- **电商透明对账** — 农产品电商交易对账可视化
- **农文旅运营** — 乡村旅游与文化活动运营看板
- **村庄适配度评估** — 助农模式可复制性评估体系
- **可视化总控大屏** — 路演总控大屏管理台
- **隐私与安全合规** — 数据隐私保护与安全合规展示

## 技术栈

- 纯前端静态页面（HTML + CSS + JavaScript）
- 无后端依赖，支持 GitHub Pages 直接部署

## 部署

1. 推送至 GitHub 仓库
2. 仓库 Settings → Pages → 选择 `main` 分支 `/ (root)` 目录
3. 访问 `https://你的用户名.github.io/仓库名/`
