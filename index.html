准则层四类（报告第二章）：人口适配度、资源适配度、基础条件适配度、组织与外部支持；对应二级指标 C1–C12（表 7 分级）。 下图二为资源—可行性耦合气泡图（研学评估矩阵同款结构）；下部为每个村单独展开：四维准则 + C1–C12 柱状可视化 + 明细表 + 未达标帮扶清单。

展开：A / F / RVCPM 计算公式

设 Ci′ = Ci / 100（将表 7 换算到 0–1）。

资源吸引力 A = 0.35·C4′ + 0.35·C5′ + 0.30·C6′

落地可行性 F = 0.25·C7′ + 0.25·C8′ + 0.15·C9′ + 0.20·C10′ + 0.15·C11′

耦合势能 RVCPM = √(A² + F²)；气泡半径按各村 RVCPM 相对本片最大值归一。

C1–C3、C12 计入各村民政教育侧综合呈现与帮扶规则；与 A/F 并联展示。完整权重以 AHP 一致性检验后的矩阵为准。
